### Serve behind a public HTTPS URL without OpenTunnel

`tlo-mcp --public-url https://example.com` listens on `0.0.0.0` and reports `https://example.com/mcp` as the endpoint instead of opening an OpenTunnel. Use it on an always-on host that already has HTTPS, such as an Amp Box. This mode needs an existing Orbit session: run `tlo-mcp login` on a machine with a browser and copy `session.json` to the host.
