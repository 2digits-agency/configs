### Report browser APIs read during render

- Added `react-extra/no-browser-api-in-render` to the React config. It reports reads of `window`, `document`,
  `navigator`, `localStorage` and `sessionStorage` (also through `globalThis`) in a React component or hook body, or in
  a `useState`, `useReducer` or `useMemo` callback. The server render cannot see these values, so the first client
  render differs and hydration fails. A `typeof window` or `IS_SERVER` guard does not help, because the guard is what
  makes the two renders differ.
- Read the value in `useEffect`, or subscribe with `useSyncExternalStore` and a server snapshot. Effects, event handlers,
  other callbacks and `useSyncExternalStore` snapshot functions are not reported.
