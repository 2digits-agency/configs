### Add opt-in ManagedRuntime disposal ownership checks

- Added `2digits/require-managed-runtime-disposal` for used private, non-escaping runtime bindings without visible
  release evidence. The rule respects import aliases, shadowing, disposal references, async disposal, and uncertain
  ownership escapes.
- Kept the rule out of recommended defaults and provided no automatic fix. Missing ownership evidence does not prove
  a resource leak; visible release evidence does not prove execution on every exit. Intentional process lifetime can
  be documented with a suppression.
