### Report `dangerouslySetInnerHTML` as an error

- `react-extra/dom-no-dangerously-set-innerhtml` (ESLint) and `react/no-danger` (Oxlint) are now errors instead of warnings, because unsanitised HTML passed to `dangerouslySetInnerHTML` is an XSS risk.
- Existing uses now fail lint. Sanitise the HTML (for example with `DOMPurify.sanitize`) and add a disable comment that states why the use is safe, such as `// eslint-disable-next-line react-extra/dom-no-dangerously-set-innerhtml -- sanitised with DOMPurify` (or `react/no-danger` for Oxlint).
