### Detect duplicate Effect HTTP API endpoints

Report duplicate literal endpoint names or exact method/path pairs within one proven Effect HTTP API group, including
aliased imports and immutable local endpoints. The diagnostic points to the later registration and identifies the
earlier site. Independent groups and intentional trailing-slash routes remain unchanged; no autofix is offered.
