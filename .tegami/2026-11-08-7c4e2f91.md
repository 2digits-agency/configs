### Report booleans and nullish values in template literals

- `ts/restrict-template-expressions` and its Oxlint counterpart `typescript/restrict-template-expressions` now set `allowBoolean: false` and `allowNullish: false`; numbers stay allowed.
- Template literals that interpolate a `boolean`, `null` or `undefined` value now report an error. For example, `` `review${count > 1 && 's'}` `` renders `reviewfalse`, and `` `/${slug?.trim()}` `` can render `/undefined`.
- To fix existing code, use a conditional (`` `review${count > 1 ? 's' : ''}` ``), provide a fallback (`slug ?? ''`), or wrap the value in `String()` when the text output is intended.
