### Bundle TypeScript 6 for typescript-eslint

`typescript-eslint` 8.x declares `typescript: ">=4.8.4 <6.1.0"` as a peer dependency, so it cannot run on
TypeScript 7. Both packages now depend on TypeScript 6 directly, which satisfies that peer from inside the
package instead of from your project.

No `typescript` peer dependency is added, so a project on TypeScript 7 installs nothing extra and keeps
using its own version everywhere else. Verified against packed tarballs installed into a TypeScript 7 only
project with both pnpm and npm: `typescript-eslint`, `@typescript-eslint/parser` and `@typescript-eslint/utils`
load TypeScript 6.0.3 there, while the project root stays on 7.0.2.

The trade-off is a nested copy of TypeScript 6 for projects that are not already on a 6.x release.
