### Add opt-in `no-json-boundary-type-assertion`

Added a diagnostic-only rule for unchecked type claims directly on parsed JSON and explicitly annotated Web JSON
readers, including generic targets. The rule preserves conservative binding/provenance checks, offers no automatic
fixes, and remains outside the recommended rules. Configured globals are now distinguished from local shadows.
