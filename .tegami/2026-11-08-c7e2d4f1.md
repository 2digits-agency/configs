### Disallow type assertions on object and array literals

- `consistent-type-assertions` now reports `{ ... } as Type` and `[ ... ] as Type`, also when passed as an argument. Use a type annotation or `satisfies Type` instead, so TypeScript checks the literal instead of trusting it. `as const` is still allowed.
- `@2digits/eslint-config` now enables `ts/consistent-type-assertions` with the `as` assertion style, matching `@2digits/oxlint-config`.
