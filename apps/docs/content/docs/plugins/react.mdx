---
title: Custom React rules
description: Four local rules embedded in the shared ESLint React integration.
---

These rules are registered under `react-extra` by the [ESLint config](/docs/configs/eslint) when its React integration is enabled. They are not standalone exports from `@2digits/eslint-plugin` and do not have a separate npm package.

| Rule                                          | Implementation                                                                                                                                        |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `react-extra/no-unnecessary-use-callback`     | [Callback checks](https://github.com/2digits-agency/configs/blob/main/packages/eslint-config/src/rules/react/no-unnecessary-use-callback.ts)          |
| `react-extra/no-unnecessary-use-memo`         | [Memoization checks](https://github.com/2digits-agency/configs/blob/main/packages/eslint-config/src/rules/react/no-unnecessary-use-memo.ts)           |
| `react-extra/prefer-destructuring-assignment` | [Destructuring checks](https://github.com/2digits-agency/configs/blob/main/packages/eslint-config/src/rules/react/prefer-destructuring-assignment.ts) |
| `react-extra/prefer-namespace-import`         | [React import policy](https://github.com/2digits-agency/configs/blob/main/packages/eslint-config/src/rules/react/prefer-namespace-import.ts)          |

All four are enabled at error level. Other `react-extra` rules come from the upstream React plugin rather than local implementations.

## Customize

```js
import twoDigits from '@2digits/eslint-config';

export default await twoDigits({
  react: {
    enable: true,
    overrides: { 'react-extra/no-unnecessary-use-memo': 'off' },
  },
});
```

These rules have context-dependent checks. Read their implementations and tests before assuming that every callback, memo, property access, or import is diagnosed.
