## Configs and plugins

A **config** selects rules and defaults for a tool. A **plugin** implements custom rules. The shared lint configs register our plugins for you; use the plugin guides when you want to register them independently.

The [rule reference](/docs/rules/oxlint) is generated from the current source. It records rule IDs, diagnostic messages, options, automatic fixes, and actual recommended-preset membership. The [plugin guides](/docs/plugins) explain how to use them.
